**Goal and acceptance:** Fix five concrete flow, async-guard, grammar, accessibility, navigation, and audio bugs across the learning screens:
1. **Quiz async submission, single-finish guard & fair retry (`lib/features/quiz/quiz_screen.dart`):**
   - Lock option tiles while `_submitting || _submitted || _finishing` so a tap mid-save cannot mutate `_selected`.
   - Guard **Finish Quiz** with `_finishing` set synchronously before awaiting `recordQuizRun` so rapid repeated taps (including while `recordQuizRun` is still pending) record exactly **one** attempt, grant one reward, and push `ChapterCompletedScreen` once; release `_finishing` in `finally` if saving throws so the learner can retry. 2. **Story `resumeSceneIndex` off-by-one (`lib/features/story/story_screen.dart`, `lib/features/chapters/chapter_detail_screen.dart`):**
   - Finishing scene `i` must call `openChapter(chapter.id, i + 1)` (the next step to resume at, not the scene already finished). Guard empty `scenes` / `dialogue` safely.
   - In `ChapterDetailScreen`, when `started && resume >= chapter.scenes.length` (all story scenes finished, grammar/quiz remaining), show an accurate ready-for-lesson status (never `"Scene 4 of 3"`) and route **Resume** to `GrammarLessonScreen.routeName` (`arguments: chapterId`); when `started && resume < chapter.scenes.length`, resume `StoryScreen` at `startScene: resume` with accurate 1-based scene progress.
3. **Chapter Completed grammar & 320 dp / 200% text safety (`lib/features/completion/chapter_completed_screen.dart`):**
   - Fix `"You did an great job!"` -> `"You did an amazing job!"` (`result.percent >= 90`) and `"You did a great job!"` (`< 90`).
   - Add `tooltip: 'Close'` on the close `IconButton`, replace the unbreakable reward-chip `Row` with a centered `Wrap`, and wrap the body in `LayoutBuilder` + `SingleChildScrollView` + `ConstrainedBox` (`MainAxisAlignment.spaceBetween`) so a 320 dp phone at 200% text scale never overflows.
4. **Navigation, filter empty states & honest offline screen (`home_shell.dart`, `profile_screen.dart`, `chapter_list_screen.dart`, `offline_download_screen.dart`):**
