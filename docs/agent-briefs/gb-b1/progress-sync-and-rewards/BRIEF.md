**Repository:** `Keshab1997/GrammarBondhu` — attach in a fresh Arena Agent Mode chat (baseline `e648e6a2dcd3b7de04352659ccadb091b9e2db2e`).
**Goal and acceptance:** Fix five real progress, cloud-sync, reset, reward, and streak defects while keeping backward-compatible local & Firestore (`schema_version: 1`) snapshots:
1. **Stale cloud merge must not resurrect reviewed/fixed questions (`lib/data/models/progress.dart`, `lib/app/state/progress_controller.dart`):** Track backward-compatible per-question review change timestamps (e.g. `review_updated_at` map of ISO-8601 UTC strings on `ChapterProgress`, injectable `now` on `markQuestionForReview` / `clearQuestionForReview`). When merging snapshots, a newer clear/correct answer keeps the question out of `missedQuestionIds`, a newer wrong answer puts it back, unrelated missed questions survive on both sides, and legacy snapshots (that have `missed_question_ids` with no timestamps) still keep their missed entries unless superseded by a timestamped clear.
2. **Session-safe & race-safe cloud sync (`lib/app/state/progress_controller.dart`):** Track a monotonic session token across `connectCloudBackup` / `disconnectCloudBackup`. Both `syncCloudNow()` and `_syncLatestCloudSnapshot()` must merge the returned snapshot into current `_progress` (`UserProgress.mergeForCloud(_progress, merged)`) so local progress earned while a sync is in flight is never overwritten, and any queued or completing sync from a disconnected or superseded account session must exit without mutating `_progress`, `_store`, `_cloudSyncing`, or `_lastCloudSyncError`.
3. **Device-only Reset Progress guard (`lib/features/settings/settings_screen.dart`, `lib/app/state/progress_controller.dart`):** While `settings.cloudConnected || progress.cloudConnected`, tapping **Reset Progress** must explain that reset is device-only and ask the learner to disconnect Google in Profile first — do not clear local progress, touch cloud backup, or show `"Progress reset."` (`resetAll()` itself should also refuse/no-op when `cloudConnected`). After disconnecting, reset clears progress and preserves the learner's chosen `dailyGoalQuestions` preference.
4. **Replay coin improvement delta (`lib/app/state/progress_controller.dart`):** In `recordQuizRun`, when a replay improves `stars` so `coins > record.coinsEarned` (e.g. upgrading a 2-star run to 3 stars), grant `coins - record.coinsEarned` (matching the existing XP improvement delta) instead of leaving those coins permanently unearnable.
5. **DST-safe study days, live streak decay & UI polish (`progress.dart`, `progress_screen.dart`, `rewards_screen.dart`):** Compute calendar-day diffs via `DateTime.utc(local.year, local.month, local.day)` so DST shifts never break streaks; add `activeStreakOn(DateTime now)` (returns `streakDays` when `lastStudyDate` is today or yesterday in local time, else `0`) and backward-compatible `bestStreakDays` (`best_streak_days`) so the `3-Day Streak` achievement stays earned once reached; make `mergeForCloud` pick coherent streak state (`bestStreakDays = max`, and current `streakDays` aligned with the fresher `lastStudyDate`, taking max when same day); in `ProgressScreen`, pass `now` (not `DateTime.now()`) to `_StreakStrip`, display `p.activeStreakOn(now)`, and rename `'Quiz Answers'` -> `'Quizzes Finished'`; in `RewardsScreen`, add optional `this.now`, display `p.activeStreakOn(now ?? DateTime.now())`, and use bottom padding `108` (`EdgeInsets.fromLTRB(AppSpacing.md, AppSpacing.md, AppSpacing.md, 108)`) so the floating `HomeShell` nav bar never covers the last achievement card.
6. **Tests:** Add offline fake-backup and unit/widget regressions in `test/cloud_progress_backup_test.dart`, `test/progress_review_test.dart`, and `test/progress_store_test.dart` covering review removal vs stale cloud + re-add, legacy snapshot compatibility, in-flight local edit survival, late sync after disconnect & account switch, connected-account reset block + post-disconnect reset preserving `dailyGoalQuestions`, 2-star -> 3-star coin delta, and DST/stale-streak decay.
